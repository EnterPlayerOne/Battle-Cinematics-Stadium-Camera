# Dynamic-Battle-Cinematics
Adds cinematic idle battle cameras to Pokémon Gen1 Recomp. Includes the DW3 Classic preset, based on the idle animations of Digimon World 2003. This is a pure alpha with ambitions of supporting multiple idle camera presets as well as a dynamic camera that operates freely based on the established Pokémon heights. when selecting a move and proceeding with turns, the camera will swing back to the standard view. upon completion of turns, it should resume the animation where it left off.

Current compatibility

✓ Dramatic Shape 1.6.1 is a prerequisite.
At this time, first person Kanto is a known incompatibility following the release of Dramatic Shape 1.6.1, the Stadium function, pokewalker, follower EX, Wilds tested and function just fine (without first person update). 

as an Alpha, this is an overlay.

installation:

download and unzip Dramatic Shape 1.6.1.
download and unzip Dynamic Battle Cinematics 0.3.0.
copy and overwrite the files from the extracted Dynamic Battle Cinematics to the Dramatic Shape 1.6.1 folder. Compress this folder and name as you wish. you must remove any other instance of Dramatic from recomp first. install the new zip and enjoy, for 4 hours until the next update from the mad man of Spain.
